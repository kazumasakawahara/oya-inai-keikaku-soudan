# 朝の支度の手順（P_900）

> 単文で言い切れる関わり方（「静かな部屋で5分待つ」等）は構造化DB側の CarePreference が正本。**このページが持つのは、順序と分岐と例外**である（→ `docs/dual-intake-routing.md` §3 の5・6）。

## 手順

1. 顔を洗う
2. 着替える
3. 朝ごはん
4. 歯磨き

**この順番が崩れると、その先が進まなくなる。**「今日は時間がないから歯磨きを先に」といった入れ替えをしない。順番を守ることが結果的に最短になる。

## 分岐・例外

- **天気が悪い日**: 全体に時間がかかる。**15分早く起こす**
- **ボタン**: 2026年6月ごろまでは手伝いが必要だったが、**2026-08-05 時点では自分でできるようになっている**（下記「変化の記録」参照）
