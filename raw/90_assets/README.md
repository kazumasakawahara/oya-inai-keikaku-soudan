# 90_assets

**入れるもの**：写真・動画・音声などのメディア類、特定の本人・提供元に紐づかない参考文献（`参考資料/`）、raw/ 自身の運用記録（`_移動記録_*.md` 等）。

**大事な線引き**：**出所の軸が先、形式の軸は最後の受け皿**。提供元が明確なバイナリはその提供元の棚へ入れる（診断書PDF → 50_医療から、会議資料PDF → 20_会議、審判書スキャン → 40_後見・法律から）。ここに落ちるのは「出所で分類できないもの」だけ。

> 写真・動画は `photos-videos/` サブフォルダへ。raw/ 内の移動記録（`_移動記録_*.md`）もここに置かれます（git 管理外・ローカルのみ）。
