## ④ モニタリング — P_900

```
モニタリングとして受け取りました。
　要点と判断の過程 → Vault の monitoring（monitored_on: 2026-08-05）
　確認できた事実 → Neo4j に Review 1件（source: 支援者に確認）＋ CONFIRMS を NgAction と CarePreference へ → lastConfirmedAt を 2026-08-05 に更新
　同じ日付を Vault の該当ページの last_confirmed にも反映
　「ボタンの手伝いが不要になった」→ Vault の protocol を更新（変化の記録として旧記述も残す）
　「会計で焦る／先に財布から出しておくと落ち着く」→ Neo4j の CarePreference（新規）＋ Vault の trigger（distress / 社会的）
　「ひとりで駅まで行ってみたい」→ Neo4j の Wish（本人の口から出た初回として date つき）
　禁忌の新規追加なし → **CONFIRMS を持たない Review** も1件作成（「確認したうえで0件」の記録）
違っていたら教えてください。
```

> **本設計の心臓部**。「確認したうえで無い」は Neo4j の Review でしか表せないため、0件確認は Neo4j 正本。
