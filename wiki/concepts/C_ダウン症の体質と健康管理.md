# ダウン症の体質と健康管理

> 東京ダウンセンター・小野正恵医師の言葉「**ダウン症は、ひとつの体質や特性なのです**」を起点に、成人期の合併症を「病気」ではなく「**体質に応じた継続的健康管理の対象**」として整理する。
>
> 支援者は、医師ではないが本人の傍にいる時間が長い立場として、**早期サインに気づく目** を持つことが本人の健康と尊厳を守る。
>
> **本ページの位置づけ（2026-04-29追記）**: 本ページは日本臨床医（小野・水野医師ら）の臨床知に基づく整理であり、世界的エビデンスベースガイドライン（GRADE方法論）に基づく [[C_ダウン症成人診療ガイドライン_GLOBAL]] と相補的関係にある。両者を併せて参照することで、暗黙知と形式知の両面から本人の健康管理を支える。

## 1. 「体質」というフレーミングの意義

> ダウン症は、ひとつの体質や特性なのです（小野医師）

- 「病気」「障害」と捉えると、合併症のひとつひとつが「悪化」「異常」として記述される
- 「体質」と捉えると、合併症は「この体質と付き合うために定期的に確認する項目」として記述される
- 後者のフレームは、本人を病理化せず、生涯を通じた健康管理の主体として位置づける
- → [[purpose]] A-1「臨床記録になってはならない」と整合

このフレームは [[C_氷山モデル]] とも親和性が高い。「困った合併症」を「水面上の現象」として処理せず、体質という水面下の地形図として理解する。

## 2. 老化のスピード

> ダウン症の生命予後はこの数十年で飛躍的に伸びましたが、さまざまな**老化現象が一般人に比べて20〜30年以上早い**と言われます（小野医師）

- 20歳台でも甲状腺機能異常が出る
- 30歳台で歯が抜けることがある
- 40歳台でアルツハイマー型認知症が増加
- → 「年齢相応の健康管理」ではなく、**実年齢よりも前倒しのチェック**が必要

これは支援者にとって重要：「まだ若いから大丈夫」という常識的判断が通用しない領域がある。

→ 本ページの「早期サイン中心」のアプローチに加え、年齢別スクリーニングスケジュール（21歳〜甲状腺、30歳〜糖尿病、40歳〜認知症等）の包括的整理は [[C_ダウン症成人診療ガイドライン_GLOBAL]] §5 を参照。

## 3. 主要な合併症と早期サイン

> 以下は支援者が「気づく」ためのチェックリストとして整理する。確定診断は医師の領域だが、支援者の気づきが受診の起点になる。

### 3-1 甲状腺機能異常症（最重要）

- **頻度**: 成人期のダウン症の方の約1割に異常値（米国データでは39〜61%）
- **重要な特徴**: ダウン症の場合は性差がなく男女ともにハイリスク
- **甲状腺機能低下症**: 全年齢で見られる。症状が緩徐で気づかれにくい
- **甲状腺機能亢進症**: 思春期前後〜20歳代に多い。体重減少・手の震え

#### 早期サイン（支援者が気づける範囲）

- 元気がない・疲れやすい
- 寒がりになった
- 体重の不自然な増減
- 便秘がち
- 動作が緩慢になった
- 抑うつ的になった

→ これらは [[C_ダウン症と急激退行]] とほぼ重なる。**急激退行を疑ったら、まず甲状腺をチェックする**。

#### 推奨される定期検診

- 年1回、TSH・FT3・FT4・抗マイクロゾーム抗体・サイログロブリン
- 自己抗体陽性の場合は短い間隔で
- 小児期に甲状腺関連治療歴がある人は成人期にも再発し得るので継続検査

→ GLOBAL ガイドラインの公式推奨は「**21歳から1-2年毎にTSH測定**」（[[C_ダウン症成人診療ガイドライン_GLOBAL]] §4-3）。日本臨床の年1回フルパネルと並べて、本人の状況に合わせて選択する。

### 3-2 睡眠時無呼吸（頻度が高い）

#### 解剖学的背景

- 上顎の低形成
- 巨舌
- 上咽頭の解剖学的狭さ
- 肥満による頸部圧迫
- 扁桃肥大

#### 早期サイン

- 強いいびき
- いびきが10秒以上止まる
- 寝つきが悪い
- 日中の眠気
- 夜間の覚醒
- うつぶせ寝（無意識の対処行動）
- 行動上の問題（イライラ・集中困難）

#### 重要な臨床的含意

> 周りへの関心が無くなった成人の方に難聴や睡眠時無呼吸が進行していた例もあります（愛知県コロニー資料）

→ 「やる気がない」「コミュニケーションが減った」と評価される変化の背後に、睡眠時無呼吸や難聴が隠れていることがある。**安易に「退行」「認知症」と判断しない**。

### 3-3 視覚・聴覚の問題

- 成人期に早期白内障を発症することが多い
- 一般人と同様に老化に伴い緩徐に難聴が進む（早期から進む例もある）
- 本人は **「見えにくくなった」「聞こえにくくなった」を言葉で適切に伝えられない** ことが多い

#### 支援者が観察すべきサイン

- いつも顔を傾けている（片側難聴の可能性）
- 斜めにものを見る（視野の問題）
- 周りへの関心の低下（視覚・聴覚の低下が背景）
- 呼びかけへの反応の低下

#### 推奨される定期検診

- 数年に一度は眼科受診
- 数年に一度は耳鼻科受診と聴力評価

### 3-4 歯科の問題（極めて重要）

#### 頻度と特徴

- ダウン症成人の約**80%が重度の歯周病**に罹患
- 歯根が短い体質的特徴
- 30歳代から歯が抜けることがある
- 入れ歯の装着が困難な例が多い

#### 連鎖するリスク

```
歯周病 → 歯の喪失 → 咀嚼困難 → 丸呑み → 窒息リスク
                              → 食物誤嚥
歯の喪失 → かみ合わせ不良 → 嚥下困難
歯周病 → 歯周病菌の唾液中誤嚥 → 誤嚥性肺炎
```

#### 支援者の関わり

- かかりつけ歯科医を決めて定期受診
- 歯石除去・虫歯の早期治療
- 介助磨きへの本人の同意形成（[[CD_意思決定支援]] と接続）
- 自立心・自尊心を尊重した関わり方

### 3-5 高尿酸血症・痛風

- ダウン症成人の半数近く
- 個人差が大きい（小児期から高値の人もいれば、生涯正常範囲の人もいる）
- 肥満や食習慣と必ずしも相関しない（体質要因が大きい）
- 舌が大きく顎が小さいため、水を大量に飲みにくい体質

#### 支援者の関わり

- 水分摂取をこまめに勧める（標準体重の成人で1日2000ml推奨）
- 年1回の血清尿酸値チェック
- 治療開始基準は一般成人より緩めに設定する医師が多い

### 3-6 肥満症

- 全員が肥満傾向ではない（やせ形もまれではない）
- BMI基準は一般成人を対象としたものなので、ダウン症の方は約半数が「肥満」に分類されてしまう
- 一般成人の基準カロリーは当てはまらない
- 個別のカロリー設定が必要

#### 肥満化の要因

- 運動量が少なく基礎代謝が低い
- 舌が大きく口腔容積が狭いため、丸呑み傾向
- 食物嗜好の偏り（強いこだわり）
- 学校卒業後の就労通所施設での運動量低下
- 特定食品への極端なこだわり（毎日コーラ1本、毎日同じカップ麺等）

→ 食のこだわりを医学的観点だけで「制限」として処理すると、本人の自己決定権を侵害しかねない。「健康管理」と「本人の選好の尊重」のバランスをとる枠組みは **[[CD_食と権利擁護]]** 参照。チョイスボード・PECS等の意思決定支援ツール、LRA（最小制約の原則）、ジレンマの判断枠組み（多職種連携・長期視点・楽しい時間の保障）が、肥満傾向のあるダウン症の方への支援にも直接応用できる。

### 3-7 排尿の問題

- 子どもの頃から **排尿間隔が長い** 体質的特徴
- 成人後も排尿困難・失禁などを伴うことがある
- 自ら尿意を伝えることが少ない方には **定時排尿の習慣化** が有効
- 泌尿器科（特に小児の排尿に詳しい医師）への相談が望ましい

### 3-8 環軸椎不安定症

- ダウン症成人の約10%
- 脊髄損傷リスクは不明
- 年1回の定期診察で脊髄症の症状（歩行運動の変化、手足の脱力感、新たな失禁、頭の挙上困難等）を確認
- 兆候があれば適切な検査を行う

→ GLOBAL ガイドラインは「**頸椎X線撮影は症状がない限り行わない**」を明示（[[C_ダウン症成人診療ガイドライン_GLOBAL]] §4-4）。**症状トリアージ**が原則であり、画像所見上の不安定性があっても脊髄損傷リスクは高くない、という近年のエビデンスを踏まえた運用が望ましい。

### 3-9 糖尿病

- イギリスの研究では、ダウン症成人の糖尿病有病率は一般集団より極めて高い
- 肥満のある方: 21歳から2〜3年毎にHbA1cまたは空腹時血糖値
- 肥満のない方: 30歳から3年毎

→ GLOBAL ガイドラインの公式推奨と一致（[[C_ダウン症成人診療ガイドライン_GLOBAL]] §4-2）。

### 3-10 精巣腫瘍（男性）

- ダウン症患者で唯一発生頻度が増加する固形腫瘍
- 定期健康診断で精巣のしこり・腫れを確認

### 3-11 円形脱毛・皮膚

- 円形脱毛: 免疫反応の関与説あり。**新学期や担任の交代等の生活変化に対する反応**として出現することも多い → [[C_ダウン症と急激退行]] と同じ機序
- 皮膚の脆弱性: 皮脂腺の開口部が大きく、毛嚢炎・膿痂疹ができやすい
- 背部肩胛骨内側周辺は自分で洗いにくく、清潔保持に注意

### 3-12 先天性心疾患の継続管理

- 最も頻度の高い内部合併症
- 小児期に診断済みのことが多い
- 成人期にも僧帽弁逆流・大動脈弁逆流等の弁疾患が報告されている
- 疲労感の増悪・息切れ・労作時呼吸困難・新たな心雑音等があれば心エコー検査

## 4. 認知症との鑑別（極めて重要）

> アルツハイマー型認知症の有病率はダウン症のある成人で増加するが、**40歳以下での発症は極めて稀**（愛知県コロニー資料）

### 40歳未満で「認知症のような症状」が出たら

→ **まず身体疾患を疑う**：

- 甲状腺機能低下症
- 睡眠時無呼吸
- 難聴・視覚障害
- うつ・適応障害
- → [[C_ダウン症と急激退行]] へ

### 40歳以上のベースライン評価（愛知県コロニー資料）

40歳から毎年、以下6領域でベースラインからの変化を評価することが推奨されている：

1. 認知・記憶・遂行行動
2. 行動と性格
3. コミュニケーション
4. 適応機能
5. 歩行及び運動能力
6. 習得された機能の全体的な低下

→ 支援者の日常観察が、医療側の早期発見に直結する。

→ この6領域は GLOBAL ガイドラインが推奨する **NTG-EDSD（National Task Group—Early Detection Screen for Dementia）** の6領域と実質的に同じ（[[C_ダウン症成人診療ガイドライン_GLOBAL]] §4-1）。GLOBAL ガイドラインでは「**40歳から年1回の認知症スクリーニング**」が**唯一の Strong recommendation** となっている。

## 5. 採血・医療場面での本人ペースの尊重

> ダウン症のある人は不安が強くて採血に抵抗する場合が少なくない。一旦本人が納得すれば以後問題なく行えるようになることが多い（愛知県コロニー資料）

### 推奨される進め方

- **わかりやすく説明し、本人が納得するのを待ってから採血を行う**
- 初回は採血の手順と説明だけにして、次回や次々回に実施するくらい時間をかける
- 初めて訪れる医療機関では不安が強いため、まず新しい場に慣らすことから始める

→ これは [[CD_意思決定支援]] が要請する「本人の理解と納得を待つ姿勢」の具体化そのもの。医療機関の都合・効率を優先する関わりは、本人の医療への不信を生み、長期的に健康管理を阻害する。

## 6. 支援者のための日常観察ポイント

本Vaultの中核的視座から再整理すると、支援者は以下のような観察を Trigger ページや Trial 記録に蓄積していくことになる（cf. [[purpose]] §3-1暗黙知）：

### 6-1 体調の変化を捉える観察項目

- いびきの強さ・止まる時間
- 寝起きの様子・日中の眠気
- 表情の変化（笑顔の頻度・質）
- 動作のスピード
- 言葉の量・質
- 食事量と嗜好の変化
- 排尿の頻度・困難
- 体重の変化
- 皮膚状態
- 顔の傾け方・物を見る角度

### 6-2 受診時のアドボカシー

ダウン症の方の特性として、**言葉の理解や状況判断は比較的高い** が **言語表出が少ない**。発話だけから判断されると実際以上に本人の理解が低く受け止められる。

支援者は：

- 本人の意思表示を「待つ」（吃音傾向の配慮）
- 医師に本人の理解レベルを過小評価させない
- 本人の頷き・首振りの読み取りに自信がない場合、絵カード等の視覚支援を提案
- 質問に対しては、本人に直接尋ねる時間を確保する

→ [[CD_意思決定支援]] §医療場面 と整合。

## 7. 親なき後支援における実務的含意

### 7-1 健康記録の引き継ぎ

- 親が把握してきた **本人の体質と健康のベースライン** を、新しい支援者にどう引き継ぐかは本Vaultの中核課題
- 「いつもより動きが遅い」「いつもより言葉が少ない」と気づくには、**「いつも」を知る**ことが必要
- 健康に関する Joy/Distress Trigger を蓄積し、ベースラインを言語化していく

### 7-2 医療機関の維持

- かかりつけ医、眼科、耳鼻科、歯科、循環器科の継続的関係を支援
- 移行医療（小児科→成人診療科）の課題は [[C_包括的医療と移行医療]] へ

### 7-3 体質に応じた合理的配慮の蓄積

- 採血の進め方
- 検査時の本人の受容パターン
- 内服薬の飲ませ方
- 食事制限への本人の納得形成

これらはすべて [[C_合理的配慮]] の医療場面における具体化として Trial 記録に積み重ねていく。

## 8. 用語と尊厳

医学資料では「合併症」「症状」「異常値」等の語が使われるが、支援記録においては：

| 避けたい表現 | 推奨表現 |
|---|---|
| 「○○の合併症がある」 | 「○○について年1回の確認をしている」 |
| 「異常値が出た」 | 「○月の血液検査で〜の数値が出ているので、医師と相談中」 |
| 「症状が悪化」 | 「○○の状態が変化している」 |

→ [[purpose]] A-7「本人の尊厳を損なう表現の禁止」に従う。
